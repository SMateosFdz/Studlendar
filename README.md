
# Studlendar

Aplicación enfocada en la organización y
gestión de horarios de estudio para estudiantes de
educación superior


## Autor

- [@SMateosFdz](https://www.github.com/SMateosFdz)


## Instalación del proyecto en local

Intalación con npm

```bash
  npm install my-project
  cd my-project
```
    
## Ejecución en local

Clone the project

```bash
  git clone https://github.com/SMateosFdz/Studlendar
```

Ir al directorio del proyecto

```bash
  cd Studlendar
```

Instalar dependencias

```bash
  npm install
```

Ejecutar la aplicación

```bash
  npm run dev
```


## Variables de entorno

Para ejecutar este proyecto, se necesitan las siguientes variables de entorno en el fichero .env:

`CLIENT_ID`

`CLIENT_SECRET`

`DATABASE_URL`

`REFRESH_TOKEN`

`RESEND_API_KEY`
